# Generador de paletas de colores

Proyecto integrador del Módulo 1 desarrollado por Nicolás Gregorio.

## Descripción

Aplicación web estática e interactiva que permite generar
paletas aleatorias de 6, 8 o 9 colores.

Los colores se generan utilizando HSL y se convierten a HEX
para mostrarlos junto a cada muestra.

## Tecnologías utilizadas

- HTML: estructura y contenido.
- CSS: diseño visual y adaptación a distintos tamaños de pantalla.
- JavaScript: generación de colores y actualización del DOM.
- Git y GitHub: historial de cambios y alojamiento del repositorio.
- GitHub Pages: publicación de la aplicación.

## Instrucciones de uso

1. Abrir la aplicación.
2. Seleccionar la cantidad de colores: 6, 8 o 9.
3. Presionar "Generar paleta".
4. Consultar los colores y sus códigos HEX.
5. Presionar nuevamente el botón para obtener otra combinación.
